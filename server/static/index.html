Transport Chatbot

Prezentujemy tutaj przykładowy chat z naszym automatycznym agentem w tle. Agent może pełnić funkcję: spedytora, dyspozytora, administratora lub biura magazynu. Agent wyjaśnia rozmówcy w jaki sposób może mu pomóc, a następnie prowadzi go krok po kroku w stronę wykonania określonego działania. Agent może korzystać z danych źródłowych… np. Informacje o awizacji lub w rezultacie interakcji z rozmówcą wykonać określone działanie w systemie dziedzinowym np. TMS.
